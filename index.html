Chưa gắn link ứng dụng

Trang này chỉ là “vỏ” hiển thị ứng dụng kho chạy trên Google Apps Script.

  1. Trong Apps Script: Triển khai → Quản lý các bản triển khai → copy URL ứng dụng web (đuôi /exec).
  2. Mở file index.html (Hostinger → Trình quản lý tệp, hoặc trên GitHub) → dán link vào dòng var APP_URL = '';
  3. Lưu lại rồi tải lại trang này.

Link hiện tại không đúng dạng https://script.google.com/macros/s/…/exec
